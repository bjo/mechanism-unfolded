금색 입력 · 파랑 공통 선기어 · 청록 출력드래그 회전 · Shift 이동 · 휠 확대

3단 Simpson 구조를 택해 연결 원리를 먼저 다룹니다. 실제 A130의 제조 치수·잇수·변속 맵을 복제한 것은 아닙니다. 내부 클러치·브레이크는 외장을 생략한 열린 형태이며, 원웨이 클러치는 조립체로 표시합니다. 유체 입자는 흐름 설명용입니다.

제작 기준 · 검증 범위

입력 → 앞 링기어(C1), 입력 → 공통 선기어(C2), 앞 캐리어와 뒤 링기어 → 출력의 연결을 유지했습니다. B2와 F1은 직렬로 선기어를 붙잡고, B3와 F2는 뒤 캐리어를 병렬로 붙잡습니다. 내부 스프래그의 접촉 형상, 밸브 바디의 모든 스풀과 유로, 유체 해석·마찰열·실차 가속은 생략했습니다. 제어 그림은 유압 명령과 체결 결과를 나타내며 실제 밸브 바디 도면이 아닙니다.
