구성
기본 01–07: 태엽 / 기어열 / 탈진기 / 밸런스 / 시·분침 / 용두 / 초침·동축
심화 08–12: 오토매틱 / 날짜 / GMT / 문페이즈 / 크로노그래프 측정·누적·리셋
?lesson=10 등의 주소로 챕터를 직접 열고 새로고침할 수 있습니다.

수정 및 검토
- 용두 보정 전달계: 직각 입력축, 전달 기어, 편심 핑거와 인덱스 휠을 전체/확대 뷰에 공유. GMT/달판 이동은 접촉 구간에 동기화. 보정 핑거 형상과 행정은 교육용 단순화.
- 태엽통 래칫 휠은 브리지 표시와 독립. 초록 클릭은 barrel 선택 그룹에 포함.
- 전체 챕터 조작계는 3D 위, 챕터 안내는 설명 칼럼 위에 배치.
- 기본 용두는 감기/시간 맞춤의 두 위치. 날짜·GMT·달 위상은 중간 위치에서 독립 보정. 교육용 선택이며 실제 칼리버의 위치 구성은 다를 수 있음.
- 3D 옆 설명 칼럼: 입문·흐름 / 선택한 부품 / 왜 이렇게 만들었을까요 탭. 데스크톱 독립 스크롤, 모바일 세로 배치.
- 심화편은 기본 시계 + 현재 선택한 컴플리케이션 하나만 표시. 이전 기능은 누적 표시하지 않음.
- 전체/확대 크로노그래프의 반환 기어, 측정축, 바늘을 같은 상태로 동기화.
- 푸셔는 크로노그래프 기구 층에 배치. 컬럼 휠 옆 푸셔: 시작·정지, 해머 옆 푸셔: 리셋.
- 분 넘김 인덱스 휠과 누적 휠, 두 하트 캠과 해머를 포함.
- GMT 2:1 감속과 독립 시차 조정, 24시간 눈금.
- 59치 달판, 두 개의 달, 곡선 표시창, 신월/보름 예제 및 보정.
- 날짜와 달판은 자정 경계의 수치 오차를 보정. 역방향 시간 맞춤은 달판을 되돌리지 않음.
- 기본/심화 메뉴 구분, 12개 챕터 전환, 390px 모바일 폭 검토.
- 스타일 분리, 커리큘럼 모듈 분리, 달력 계산과 렌더링 분리.
- 미사용 이전 결과 이미지·작업 스크립트는 이 게시용 묶음에서 제외.

검토 시 권장 순서
10 GMT: +1시간 → 12시간 진행. 현지 시침 1회전 / GMT 반 회전 비교.
11 문페이즈: 하루 진행 → 달판 한 칸 전진. 덮개 열기 → 두 달 확인.
12 크로노그래프: 태엽 감기 → 푸셔 시작 → 전체/확대 전환 → 정지.
12 크로노그래프: 58초부터 분 넘김 → 정지 → 리셋 예제와 접점 관찰.
구조 펼치기·다이얼 보기·투시를 조합해 각 층과 축을 확인하세요.

모델의 범위
특정 칼리버를 복제한 제작용 CAD가 아니라 작동 원리를 위한 자체 기하 모델입니다.
기어비·회전 방향·표시 상태는 검증했지만 전 부품의 체적 충돌, 토크, 마찰,
스프링 하중 및 제작 공차를 계산하지 않습니다. 푸셔 링크와 GMT 조정 칼라는
작동 경로를 읽도록 단순화했습니다. 제조 가능한 기계 설계 검증을 뜻하지 않습니다.
문페이즈는 29.5일 기본형이며 현재 실제 달의 위상을 자동 계산하지 않습니다.
시간 진행 버튼은 관찰용 시간 가속이며 실제 태엽 소모를 적산하는 기능이 아닙니다.
IAB 데스크톱 및 390px 폭에서 검토했습니다. 실제 iOS/Android 기기 검증은 별도입니다.
실제 호스팅 후 도메인·캐시·CDN 접근성 검토가 필요합니다.
